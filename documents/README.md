# File Compression Tool

## About the Project

The **File Compression Tool** is a software project focused on reducing file sizes to improve storage efficiency and make file handling easier. It explores the concepts of data compression and the efficient representation of digital information.

The repository also maintains the project's software engineering documentation, covering requirements, security considerations, user interactions, and testing. These documents help define the system's expected behavior and provide a structured reference throughout development.

## Project Objectives

- Reduce file sizes using the compression technique implemented in the project.
- Understand the principles of data compression and storage optimization.
- Define the functional and security requirements of the system.
- Document user interactions and expected system behavior.
- Establish test cases to evaluate the system's functionality.

## Documentation

The `documents/` directory contains the following project documents:

### 1. `SRS_document.pdf` — Software Requirements Specification

Describes the software requirements for the File Compression Tool. An SRS document typically defines the system's purpose, scope, functional requirements, non-functional requirements, and expected behavior. It serves as a reference for understanding what the application is intended to do.

### 2. `Security_Requirements.pdf` — Security Requirements

Documents the security considerations and requirements associated with the application. This may include protecting user files, validating inputs, handling errors securely, and ensuring that file operations do not compromise data integrity, depending on the requirements defined for the project.

### 3. `Test_Cases.pdf` — Test Cases

Contains test cases used to verify the application's functionality against its expected behavior. These may cover valid and invalid inputs, file compression, decompression, error handling, and other relevant scenarios specified for the system.

### 4. `Use_Case_Flow.pdf` — Use Case Flow

Describes the sequence of interactions between a user and the system to accomplish particular tasks. It helps illustrate the steps involved in using the File Compression Tool, including the expected flow of actions and system responses.

### 5. `User_Stories.pdf` — User Stories

Documents the application's requirements from the user's perspective. User stories help identify what users want to accomplish with the system and why those capabilities are useful, providing a user-focused view of the application's expected functionality.

## Applications

File compression is useful for reducing storage requirements, making file transfers more efficient, and managing digital files. The project provides a practical context for exploring these concepts alongside software requirements analysis, security planning, and software testing.
